# DECISIONS

Decisions that shape the React PDF Viewer site and package. A decision stands until a later entry replaces it.

| ID   | Decision                                                                                                                                                                                                                                                                                                                    |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | Plugin id `react-pdf-viewer` (the permanent docs namespace `/react-pdf-viewer/…`), display name “React PDF Viewer”.                                                                                                                                                                                                         |
| D-02 | Free only: one `free` tier, no badges, no pricing page or feature matrix. A paid edition later means new tiers, per-page `plan` values and a `pricing.json`; no URL changes.                                                                                                                                                |
| D-03 | Static, pre-rendered site with path URLs and trailing slashes, served from the root of its own origin on Cloudflare Pages (`_redirects` for HTTP 301s, a preview per pull request). Legacy `#/…` URLs redirect in the browser (E-01).                                                                                       |
| D-04 | Astro 7 site (`apps/site`) with MDX and React islands, plus the plugin-agnostic `packages/ppds-kit`: layouts, sidebar, demo toolbar, metadata, generated reference (TypeDoc), `llms.txt`, Markdown twins, sitemap, OG images, Pagefind search and the conformance checks. The kit must not contain plugin-specific strings. |
| D-05 | The standard's archetypes J (Guide), K (Section index) and L (Demo scenario) cover guides, customization, integrations, migration, FAQ/Support/Versions, section indexes and demo scenarios.                                                                                                                                |
| D-06 | The feature group for network and asset configuration is called _Connectivity_, so it never collides with the _Integrations_ section.                                                                                                                                                                                       |
| D-07 | Docs-only site for a single product: a minimal header (name, version, search, GitHub, theme), `/` redirects to `/react-pdf-viewer/`, no marketing pages, and the Playground is the one full demo (E-06).                                                                                                                    |
