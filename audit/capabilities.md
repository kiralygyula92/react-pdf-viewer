- **Package properties**, not user-facing capabilities: ESM-only build, TypeScript types, zero runtime dependencies, size budget of 20 kB (`size-limit`), MIT license. These belong on Overview, Requirements and Installation.
- **Demo-app-only behaviour**, not shipped in the package: drag-and-drop file open, deep-link parameters on `#/view` (`src`, `page`, `zoom`, `rotation`), the playground event log and container-width slider, the CORS explainer in example 12, the sample PDF generator, and the `#/harness` test fixture.
