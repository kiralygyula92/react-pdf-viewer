## What this shows

A realistic “open a document” screen, built from one controlled `PdfViewer`:

- The page, zoom and rotation are controlled by the URL query string (`src`, `page`, `zoom`, `rotation`), so the address bar is always a deep link: [Controlled state](/react-pdf-viewer/controlled-state/).
- Out-of-range values are clamped and written back: open `?src=/samples/letter-3pages.pdf&page=9`. See [Page navigation](/react-pdf-viewer/page-navigation/).
- The viewer fills the available height through CSS variables rather than fixed sizes: [Theming](/react-pdf-viewer/customization/theming/).
- URL, local file and drag-and-drop sources: [Document sources](/react-pdf-viewer/document-sources/).
- Failures such as a missing file or a CORS-blocked URL show the error view with Retry: [Error states](/react-pdf-viewer/error-states/).
