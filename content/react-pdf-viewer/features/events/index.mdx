## Basics

Pass callbacks to hear what the viewer is doing.

<Demo id="features/events/demo-basics" title="An event log" />

| Callback                                                                  | Called with                                  | When                                                                                          |
| ------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `onDocumentLoad`                                                          | `{ numPages, fingerprint }`                  | A document finished loading                                                                   |
| `onPageRender`                                                            | `{ page, scale, width, height, durationMs }` | A page finished rendering                                                                     |
| `onPageChange`, `onScaleChange`, `onRotationChange`, `onFullscreenChange` | the new value                                | The user or your code changed it; see [Controlled state](/react-pdf-viewer/controlled-state/) |
| `onError`                                                                 | `PdfViewerError`                             | Something failed; see [Error states](/react-pdf-viewer/error-states/)                         |
| `onDownload`, `onPrint`                                                   | the file, or nothing                         | Before saving or printing; return `false` to take over                                        |
| `onHttpError`                                                             | `Response`                                   | A URL source returned a non-2xx status                                                        |

`fingerprint` identifies the document's content, which is handy as a cache or analytics key. Callbacks can change between renders without reloading anything.

## Advanced / escape hatch

`PdfPageCanvas` has its own `onRender` and `onError` for [headless](/react-pdf-viewer/headless/) layouts.

## Limitations

- **No scroll or selection events.** The viewer does not report scroll position or text selection. Workaround: listen on the document area yourself (`.rpv-viewport`) or use `document.getSelection()` with the [text layer](/react-pdf-viewer/text-layer/).
- **`onPageRender` fires often.** It fires after every render, including re-renders after zoom and resize. Workaround: debounce it before sending analytics.
