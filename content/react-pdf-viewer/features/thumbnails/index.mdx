## Basics

`thumbnails` adds a sidebar with a small preview of every page; the current page is highlighted.

<Demo id="features/thumbnails/demo-basics" title="Page thumbnails" />

Thumbnails render lazily as they scroll into view, so a long document costs nothing until the user looks at it. Each thumbnail is a button labelled with its page number, and the sidebar is a named navigation region.

## Customization

The sidebar width and the highlight colour are CSS variables; the sidebar's accessible name comes from `labels.thumbnails`.

<Demo
  id="features/thumbnails/demo-customization"
  title="A narrower sidebar with an orange highlight"
/>

See `--rpv-thumbnails-width` and `--rpv-accent` in the [CSS variables reference](/react-pdf-viewer/api/css-variables/) and the [customization guide](/react-pdf-viewer/customization/).

## Advanced / escape hatch

For a thumbnail strip in your own layout (for example horizontally under the page), use [`PdfPageCanvas`](/react-pdf-viewer/headless/) with a small `scale` or `fit` box.

## Limitations

- **Hidden in compact layouts.** Below `compactBreakpoint` the sidebar is hidden outside fullscreen, because it would take too much of a narrow screen. Workaround: lower `compactBreakpoint`, or build a horizontal strip with [`PdfPageCanvas`](/react-pdf-viewer/headless/).
- **Thumbnails stay rendered.** A thumbnail is kept once it has been shown, so memory grows with the number of pages scrolled past. Workaround: a [headless](/react-pdf-viewer/headless/) strip that renders only what is on screen.
- **The sidebar is on the left.** Its position is fixed. Workaround: a [headless](/react-pdf-viewer/headless/) layout.
