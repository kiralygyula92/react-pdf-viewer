React PDF Viewer is free and open source, so support happens in the open on GitHub.

## Free channels

- **Bug reports:** open an [issue](https://github.com/kiralygyula92/react-pdf-viewer/issues/new/choose) with the bug report template. Include the package and `pdfjs-dist` versions, your browser, and a minimal reproduction; a sample PDF helps most.
- **Feature requests:** open an issue with the feature request template and describe the problem you want to solve, not only the solution.
- **Questions:** search existing [issues](https://github.com/kiralygyula92/react-pdf-viewer/issues) first; if nothing matches, open an issue.
- **Contributing:** see [CONTRIBUTING.md](https://github.com/kiralygyula92/react-pdf-viewer/blob/main/CONTRIBUTING.md). Participation follows the [Code of Conduct](https://github.com/kiralygyula92/react-pdf-viewer/blob/main/CODE_OF_CONDUCT.md).

Before reporting, check the [FAQ](/react-pdf-viewer/getting-started/faq/) and the Limitations section of the feature you are using.

## Reporting a security issue

Please do **not** open a public issue for a vulnerability. Report it privately through [GitHub security advisories](https://github.com/kiralygyula92/react-pdf-viewer/security/advisories/new), with the affected version, the impact and ideally a reproduction (for example a crafted PDF). Vulnerabilities in PDF.js itself should be reported to Mozilla. The full policy is in [SECURITY.md](https://github.com/kiralygyula92/react-pdf-viewer/blob/main/SECURITY.md); see also the [Security guide](/react-pdf-viewer/guides/security/).
