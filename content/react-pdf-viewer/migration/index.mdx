---
title: Migration
description: Upgrade guides between versions of React PDF Viewer, one page per version jump with breaking changes.
---

Each release with breaking changes gets a guide here listing what changed, why, and the exact code to update. React PDF Viewer is at its initial release, so there are no upgrade guides yet. Check the [changelog](/react-pdf-viewer/discover-more/changelog/) for every release and the [versioning policy](/react-pdf-viewer/getting-started/versions/#versioning-policy) for when breaking changes can happen.
