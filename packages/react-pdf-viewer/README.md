# @your-scope/react-pdf-viewer

> Work in progress. The final package name is a placeholder that the owner will choose.

An accessible, themeable React PDF viewer built on [`pdfjs-dist`](https://www.npmjs.com/package/pdfjs-dist).

## Install

```sh
pnpm add @your-scope/react-pdf-viewer pdfjs-dist
```

`pdfjs-dist` (^6), `react` and `react-dom` (>=18) are peer dependencies.

## Usage

```tsx
import '@your-scope/react-pdf-viewer/styles.css';
```

The full API documentation will be added as the milestones land.
